# Around The U.S.

## Descripción

Proyecto web que muestra una galería de lugares icónicos de los Estados Unidos.
El usuario puede editar su nombre y descripción a través de un formulario emergente.

## Funcionalidad

- Visualización de tarjetas con imágenes de lugares de EE.UU.
- Ventana emergente para editar el perfil del usuario
- Los cambios se reflejan en la página sin recargarla

## Autor

Cinthia Hernandez Sotelo

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, posicionamiento)
- JavaScript (manipulación del DOM, eventos)
- Metodología BEM
- Diseño responsivo con media queries
