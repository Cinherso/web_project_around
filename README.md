# Around The U.S.

## Descripción

Proyecto web que muestra una galería de lugares icónicos de los Estados Unidos.
El usuario puede editar su nombre y descripción a través de un formulario emergente.
Permite editar
el perfil, agregar tarjetas nuevas, dar like, eliminarlas y ver cada imagen
en grande.

## Funcionalidad

- Edición del perfil con validación de formularios
- Agregar y eliminar tarjetas
- Botón de me gusta
- Popup con la imagen ampliada
- Cierre de popups con la X, la tecla Esc o clic fuera

## Autor

Cinthia Hernandez Sotelo

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, posicionamiento)
- JavaScript (manipulación del DOM, eventos)
- Metodología BEM
- Diseño responsivo con media queries
